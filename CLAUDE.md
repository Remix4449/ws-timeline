# CLAUDE.md

## Portée de ce dépôt

`ws-timeline` est **le plugin timeline pour Grist**, et le générateur PDF qui
l'accompagne. Rien d'autre.

- **Ne jamais démarrer ici un projet sans rapport avec le plugin.** Pas de
  nouveau dossier applicatif à la racine, même « en attendant », même si c'est
  le seul dépôt ouvert dans la session.
- **Un nouveau projet = un nouveau dépôt**, sous `Remix4449`, dès le premier
  commit. Pas un dossier d'ici qu'on déménagera plus tard.
- Si la demande arrive depuis une session ouverte sur `ws-timeline` : le dire,
  créer le dépôt, s'y attacher, et y travailler — plutôt que de planter le
  projet ici en se promettant de le sortir ensuite.

Ce n'est pas une précaution théorique. Deux projets ont déjà fait l'aller-retour :
Panier Commun (sorti par la PR #3, vers `Remix4449/panier-commun`) et
l'application Patch (sortie par la PR #5, vers `Remix4449/Patch`). Chaque fois,
la copie restée ici a divergé de l'originale avant d'être retirée.

## Préférences de fonctionnement

- **Réponses courtes et concises** par défaut.
- **Privilégier les artifacts/fichiers** pour tout contenu substantiel (code, documents longs)
  plutôt que de tout réécrire dans le fil de discussion.
- **Recherche web activée**, à utiliser normalement.
- **Prévenir si la conversation devient très longue** (nombre de messages / taille des réponses
  élevés) et proposer d'en ouvrir une nouvelle.
